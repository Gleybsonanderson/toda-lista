# Lista de Tarefas

Projeto simples que fiz para praticar JavaScript puro, sem framework nenhum. É uma lista de tarefas básica: dá pra adicionar, marcar como feita e apagar.

## Tecnologias

HTML, CSS e JavaScript.

## Como rodar

Basta baixar o repositório e abrir o `index.html` no navegador. Não precisa instalar nada.

## Por que escolhi o projeto?

Estou aprendendo desenvolvimento front-end e queria treinar manipulação de DOM (pegar elementos da página, criar novos elementos dinamicamente) e eventos de clique. Achei um bom projeto pra fixar esses conceitos na prática.
